WEBSITE PROFIL DESA - TEMA BIRU

Isi folder:
- index.html : struktur dan konten website
- style.css  : tampilan, warna, layout responsif
- script.js  : menu mobile, tanggal, dan animasi angka

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder website_profil_desa_biru.
3. Klik dua kali index.html, atau buka folder dengan VS Code lalu jalankan memakai ekstensi Live Server.

PENTING:
Website ini memakai nama "Desa Sejahtera" dan data contoh (jumlah warga, KK, dusun, usaha lokal, sejarah, alamat, telepon, email).
Ganti seluruh data contoh tersebut dengan informasi resmi desa sebelum dipublikasikan.
Foto hero dan beberapa foto bagian website dimuat dari Unsplash sehingga memerlukan internet.
